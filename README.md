# Entrenador Airbus A400M Atlas v1

Simulador de vuelo de una sola página (HTML + Three.js r128), estilo «C172 básico» pero con el transporte táctico A400M.

## Instalar
Sube la carpeta tal cual a GitHub Pages (index.html, manifest.json, sw.js e iconos en la raíz). En iPhone: Safari → Compartir → Añadir a pantalla de inicio.

## Qué incluye
- Ficha de presentación del A400M (misión, motores, mandos, dimensiones, actuaciones).
- 4 palancas de gases independientes (línea ámbar = ralentí, zona roja = reversa), botón SYNC (tecla T), reversa con N.
- Arranque de motores, sidestick, flaps 0/1/2/FULL, spoilers, tren, freno.
- Fallo de motor individual (botones 1–4, ARREGLAR) con hélice embanderada y guiñada asimétrica.
- 21 lecciones (arranque → aproximación, motor parado, tren de emergencia, VOR), escenarios, checklists.
- Pista de 2 400 m en valle de alta montaña.

## Aviso
Coeficientes, posiciones de flaps y límites son estimaciones para un modelo didáctico, no datos oficiales. No sirve para entrenamiento real.
